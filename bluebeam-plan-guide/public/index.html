    4 Set up

    Assign licenses to your team

    Once your subscription is active, your admin assigns plans to people in Bluebeam Org Admin. Assign a plan to yourself first, then add your team.

    Sign in to Org Admin (Canada)app.bluebeam.ca/org-admin
    1. Select your server region
    2. Enter your Bluebeam ID (BBID) and password

    Add one user

    For a new hire or a few people.

    1. Select Users in the left sidebar.
    2. Select Add User > Add User.
    3. Enter their details and choose an access level: End User, Org Admin or IT Admin.
    4. Select Save, choose their plan, then Save again.

    They show as Pending until they accept the email invitation. People who already have a Bluebeam ID are accepted right away.

    Full guide →

    Add many users at once

    For rolling out to a whole team, up to 500 per upload.

    1. Select Users, then Add User > Bulk Add or Edit Users.
    2. Select Download CSV Template and open it in Excel.
    3. Fill in First Name, Last Name, Email and Serial Number (starts with SN).
    4. Save as CSV, drop it into the dialog and select Done.

    Use commas, not semicolons, and don't delete any template columns.

    Full guide →

    Change or reassign a plan

    For upgrades, role changes or someone leaving.

    1. Select Users in the left sidebar.
    2. Select one or more users. Filters help narrow the list.
    3. Select Modify Plan at the top of the list.
    4. Choose a plan with open seats and select Save Changes.

    No seats left? Change someone who no longer needs one to Unpaid Collaborator to free up their seat.

    Full guide →

    After a plan is assigned, each person gets an email to activate their account and create a Bluebeam ID, then signs in to Revu with it. More help in the Org Admin help center.
